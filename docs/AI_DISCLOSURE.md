# AI Assistant Disclosure

AI assistants were used to help design, implement, review, test, and document
TraceRoom during the hackathon build.

The demo uses config-defined market snapshots and real structured LLM agent
outputs. Controlled evidence, vote, risk-policy, and error scenarios are
explicitly disclosed in the UI and telemetry. AI output cannot replace the
authoritative numeric snapshot, and no real-money trading is performed.
